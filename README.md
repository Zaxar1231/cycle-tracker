**Мой цикл** — приложение для Android, которое само считает цикл: показывает день цикла, прогноз месячных и овуляции, фертильное окно и вероятность зачатия. Есть дневник самочувствия, напоминания и статистика. Без регистрации и рекламы: все данные хранятся только на телефоне, в интернет приложение выходит лишь для проверки обновлений.

## Установка
1. Нажмите **«Скачать APK»** выше и скачайте файл `cycle-tracker-v….apk` из последней версии.
2. Откройте файл на телефоне. Если Android спросит, разрешите «Установку неизвестных приложений» для браузера или файлового менеджера.
3. Готово. Дальше обновления приходят прямо в приложение.

> [!IMPORTANT]
> **Переход с версии 1.0.** Версию 1.0 нельзя обновить поверх: она подписана другим, утерянным ключом. Один раз сделайте так:
> 1. В v1.0: **Настройки → Профиль и данные → Экспорт данных (файл JSON)**, сохраните файл.
> 2. Удалите v1.0 и установите новую версию.
> 3. На экране приветствия нажмите **«Импортировать данные из файла»** (или позже: **Настройки → Профиль и данные → Импорт из файла**).

|---|---|

| 📅 **Календарь** | Цветом выделены месячные, ожидаемые дни, овуляция и фертильные дни. Значки ❤️ интим, 💊 таблетка, 📝 запись в дневнике |
| 📝 **Дневник** | Настроение, симптомы (готовые и свои), температура, выделения, заметки на каждый день |
| 📊 **Статистика** | Средняя длина цикла, история и диаграмма циклов, частые симптомы, график уровней гормонов |
| 👶 **Беременность** | Вероятность зачатия на каждый день. Режим беременности: неделя, триместр, предполагаемая дата родов |
| 💊 **Контрацептивы** | График приёма таблеток: активные дни и перерыв, время, правило (до или после еды), напоминания |
| 🔔 **Напоминания** | Таблетки, вода по часам, ежедневная проверка самочувствия, предупреждение в дни высокой вероятности зачатия |
| 🎨 **Оформление** | 6 цветовых тем (включая системную Material You), тёмная тема, 6 готовых фонов или своё фото, 4 варианта иконки |

| 🐱 **Помощник** | Питомец на выбор отвечает на частые вопросы и подсказывает, где найти функцию |
| 🧩 **Ещё** | Виджет «день цикла и фаза» на рабочий стол, совет дня, отчёт о здоровье одним файлом для врача |

## Обновления
Приложение само проверяет новые версии на этой странице: при запуске (не чаще раза в 6 часов) или по кнопке **Настройки → Обновления → Проверить обновления**. Если вышла новая версия, появится окно со списком изменений и кнопкой **«Обновить»**. Приложение скачает APK, проверит подпись и откроет установщик Android. Данные при обновлении сохраняются.

> [!WARNING]
> Ключ подписи лежит в репозитории открыто (`signing/release.p12`, пароль `cycletracker`), чтобы релизы выходили без настройки секретов. Поэтому любой может подписать этим ключом своё APK, и Android примет его как обновление. **Устанавливайте обновления только из самого приложения или со страницы [релизов](https://github.com/Zaxar1231/cycle-tracker/releases).**

## Как считается цикл
- **Длина цикла** — среднее арифметическое интервалов между последними отмеченными месячными (не больше 6 последних циклов). Если отмечен только один цикл, берётся значение из настроек (по умолчанию 28 дней).
- **Следующие месячные** = начало последних месячных + средняя длина цикла.
- **Овуляция** = следующие месячные − длительность лютеиновой фазы (по умолчанию 14 дней).
- **Фертильное окно** = N дней до овуляции (по умолчанию 5) + день овуляции + 1 день после.
- **Конец месячных** = начало + длительность из настроек (по умолчанию 5 дней).
- **Вероятность зачатия** оценивается по близости дня к овуляции: максимум в день овуляции и за 1–2 дня до неё.

Чем больше циклов отмечено, тем точнее прогноз.

## Для разработчиков
**Стек:** Kotlin, Jetpack Compose, Material 3. minSdk 26 (Android 8.0), targetSdk 35.

**Сборка в Android Studio**
1. Установите [Android Studio](https://developer.android.com/studio).
2. **File → Open** → выберите папку проекта и дождитесь синхронизации Gradle (первый раз 5–15 минут).
3. Подключите телефон с включённой отладкой по USB или создайте эмулятор (**Tools → Device Manager**).
4. Нажмите **Run** (Shift+F10).

**Из командной строки**
```bash
./gradlew testDebugUnitTest assembleDebug   # тесты и отладочная сборка
./gradlew assembleRelease                   # релизный APK: app/build/outputs/apk/release/
```
Все сборки подписываются общим ключом `signing/release.p12`, поэтому версия из Android Studio ставится поверх версии из релиза и наоборот.

**Как выпустить новую версию**
Поменяйте значение по умолчанию `appVersionName` в `app/build.gradle.kts` (например, на `"1.2"`) и влейте изменение в `main`. Workflow **Release** сам соберёт APK, создаст тег `v1.2` и опубликует релиз, а приложения у пользователей предложат обновиться. `versionCode` считается из версии (1.2.3 → 10203).

Вместо общего ключа можно подключить свой секретный: секреты `RELEASE_KEYSTORE_BASE64`, `RELEASE_KEYSTORE_PASSWORD`, `RELEASE_KEY_ALIAS`, `RELEASE_KEY_PASSWORD` в настройках репозитория. Установленные версии тогда придётся один раз переустановить.

## Важно
Это вспомогательный инструмент, а не медицинское изделие. Приложение не гарантирует точность определения овуляции и не заменяет контрацепцию и консультацию врача.
