# Мой цикл — трекер менструального цикла

Android-приложение (Kotlin + Jetpack Compose + Material Design 3) для автоматического расчёта менструального цикла.

## Возможности
- Отметка начала месячных одним касанием (кнопка «+» на главном экране)
- Автоматический расчёт: день цикла, дата следующих месячных, день овуляции, фертильное окно
- Календарь с цветовой разметкой фаз (месячные, ожидаемые, овуляция, фертильные дни) и метками ❤️ (половой акт), 💊 (таблетки), 📝 (дневник)
- Дневник на каждый день: настроение, симптомы (смайлики + свои), температура, выделения, заметки
- Вероятность зачатия в процентах на каждый день + уведомление о контрацепции в дни высокого шанса
- Уровни гормонов (эстроген, прогестерон, ЛГ, ФСГ) по фазам цикла + график в статистике
- Режим беременности: неделя, триместр, предполагаемая дата родов
- Статистика: средняя длина цикла, история циклов, диаграммы длины циклов, счётчики симптомов
- Предупреждения о нерегулярном цикле
- Совет дня
- Отчёт о здоровье одним файлом (txt)
- Виджет «день цикла / фаза» для рабочего стола
- PIN-код (4 цифры) при входе
- Трекер противозачаточных таблеток: активные дни/перерыв, время приёма, правила (до/после еды), уведомления
- Напоминания: вода по часам и ежедневная проверка здоровья
- Помощник-питомец (кошка, собака, ёжик и др.) с поиском по вопросам
- Экспорт/импорт данных в файл JSON (перенос на другое устройство)
- 6 цветовых тем (включая системную Material You), фото на задний план, выбор иконки приложения
- Тёмная тема и динамические цвета Material You (Android 12+)
- Обновление прямо из приложения: проверка новых версий в релизах GitHub, загрузка и установка APK (Настройки → Обновления)

## Требования
- Android Studio (последняя версия): https://developer.android.com/studio
- Телефон с Android 8.0+ или эмулятор
- Интернет при первой сборке (скачивание библиотек)

## Как запустить
1. Установите Android Studio.
2. File → Open → выберите эту папку.
3. Дождитесь синхронизации Gradle (первый раз 5–15 минут, нужен интернет).
4. Подключите телефон по USB:
   - Настройки → О телефоне → нажмите 7 раз на «Номер сборки» (появится режим разработчика)
   - Настройки → Для разработчиков → включите «Отладка по USB»
   - Или создайте эмулятор: Tools → Device Manager → Create Device
5. Нажмите зелёный треугольник Run (Shift+F10).

## Обновления и выпуск новой версии
Приложение проверяет последний релиз в этом репозитории (`/releases/latest`) при запуске (не чаще раза в 6 часов) или по кнопке «Проверить обновления». Если версия релиза новее установленной, приложение предлагает скачать APK, проверяет его подпись и открывает системный установщик. Данные при этом сохраняются.

Android ставит обновление только поверх приложения, подписанного **тем же ключом**. Все сборки (Android Studio, CI, debug и release) подписываются ключом `signing/release.p12` из репозитория, поэтому любая новая версия встаёт поверх старой.

⚠️ Ключ лежит в публичном репозитории открыто (пароль `cycletracker`). Это сделано намеренно, чтобы не настраивать секреты, но любой может подписать этим ключом своё APK. Устанавливайте обновления только со страницы релизов этого репозитория или из самого приложения. Ключ v1.0 утерян, поэтому v1.0 нельзя обновить до v1.1: сделайте экспорт данных, удалите v1.0, установите новую версию и импортируйте данные.

### Как выпустить новую версию
Поменяйте значение по умолчанию `appVersionName` в `app/build.gradle.kts` (например, `"1.2"`) и влейте изменение в `main`. Workflow «Release» сам соберёт APK, создаст тег `v1.2` и опубликует релиз. Если версия уже выпущена, ничего не происходит.

Свой секретный ключ можно подключить секретами `RELEASE_KEYSTORE_BASE64`, `RELEASE_KEYSTORE_PASSWORD`, `RELEASE_KEY_ALIAS`, `RELEASE_KEY_PASSWORD`, но тогда установленные версии придётся переустановить.

## Как считается цикл
- **Длина цикла** — среднее арифметическое интервалов между последними отмеченными месячными (не более 6 последних циклов). Если отмечен только один цикл — берётся настройка (по умолчанию 28 дней).
- **Следующие месячные** = начало последних месячных + средняя длина цикла.
- **Овуляция** = следующие месячные − длительность лютеиновой фазы (по умолчанию 14 дней).
- **Фертильное окно** = N дней до овуляции (настройка, по умолчанию 5) + день овуляции + 1 день после.
- **Конец месячных** = начало + настройка длительности (по умолчанию 5 дней).
- **Вероятность зачатия** оценивается по близости дня к овуляции (максимум в день овуляции и за 1–2 дня до неё).

Чем больше циклов отмечено, тем точнее прогноз.
